# MIRRORGRID

> A local-first distributed-systems reliability laboratory that models production-like service architectures, generates controlled workloads, injects deterministic failures, observes failure propagation, measures reliability, and reconstructs state through snapshots and event replay.

---

## The Central Thesis

Most "chaos dashboard" projects script their failures: the UI shows latency rising because someone hardcoded `latency = 1800ms`.

**MIRRORGRID's central claim is the opposite: the numbers are emergent, and the run is reproducible.**

Latency, queue growth, saturation, retry amplification, and cascading failure fall out of a bounded-concurrency queueing model advanced by a virtual clock. Nothing is scripted. Because every source of nondeterminism is seeded and recorded, the same experiment replays to an identical **canonical state hash**.

## Architecture & Structural Guarantees

1. **Deterministic Discrete-Event Engine (`packages/sim`)**:

   - Zero runtime dependencies, zero workspace dependencies.
   - Purity enforced mechanically by ESLint (`no-restricted-globals` banning `Date` and `Math.random`, `no-restricted-imports` banning `@mirrorgrid/*`) and `dependency-cruiser`.
   - Discrete integer-microsecond time with total event ordering `(timeUs, priority, seq)`.
   - Offline precomputed integer inverse-CDF tables preventing IEEE-754 transcendental float drift.
   - Continuous occupancy integral ensuring Little's Law closes to 0.00% error.
   - Canonical Merkle state hashing (`CanonicalSerializer.float()` typed as `never`).

2. **No-Mock-Data Rule**:

   - Zero mock files (`mock-data.ts`, `*.mock.ts`) permitted in the repository.
   - All frontend surfaces consume live backend endpoints and durable database state from M0.

3. **Two-Plane Separation**:
   - **World Plane**: Modeled services, synthetic containers, and injected chaos.
   - **Platform Plane**: Real distributed infrastructure (Fastify gateway, Control plane, PostgreSQL, and future Kafka/NATS/Redis). Real chaos here tests MIRRORGRID itself.
